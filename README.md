# Madar - Arabic Digital Services Demo

نموذج تجريبي لموقع خدمات رقمية عربي متجاوب، أُنشئ لعرض مهارات تطوير المواقع الإلكترونية.

## Features

- Arabic RTL responsive layout
- Interactive service filtering
- Package-selection interaction
- Appointment-form validation
- Interactive FAQ section
